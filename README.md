# The Worst Pizza Topping

A make.fun bounty entry: a tiny deterministic Node program that writes one funny line pitching a terrible pizza topping. The line sells an inedible, everyday object as a pizza topping, with the punchline landing on the one thing nobody wants to do after eating bad pizza — pay for it.

## Run it

```sh
node main.ts
```

It writes the single line to `/output/entry.txt`.
